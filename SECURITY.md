# 🔒 Política de Seguridad

Nos tomamos la seguridad muy en serio. Este documento describe las medidas de protección y el protocolo para reportar vulnerabilidades.

## Versiones Soportadas

| Versión | Soportada |
| :--- | :---: |
| 1.0.x (main) | ✅ |

## 🛡️ Medidas de Protección Activas
- **Aprobación Obligatoria por PR**: Ningún cambio entra a producción sin revisión previa por el propietario.
- **Auditoría Automatizada de Dependencias**: Análisis continuo con GitHub Actions y `npm audit`.
- **Privacidad Client-Side**: Los documentos se procesan directamente en el navegador del usuario sin almacenamiento persistente ni tracking de datos.

## 🚨 Reportar una Vulnerabilidad
Si descubres alguna vulnerabilidad o código sospechoso, por favor **NO abras un Issue público**.
Envía un reporte confidencial a través de la pestaña **Security** -> **Report a vulnerability** en GitHub o contacta directamente al propietario del repositorio.
